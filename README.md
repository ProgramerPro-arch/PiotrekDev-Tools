# PiotrekDev Tools

Plugin for MeshCentral that adds a **Narzędzia** tab.

## Current functionality

- trying to code a webcam acces

## Installation

1. Download or clone this repository.
2. Install the plugin using your MeshCentral plugin setup process.
3. Refresh the device page and open the **Narzędzia** tab.

## Notes

This is an early version. Device context and compatibility should be tested against the specific MeshCentral version in use. Camera, microphone, and remote command execution features are not currently implemented.
